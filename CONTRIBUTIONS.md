## 4. Kontribusi Ekstraksi dan Verifikasi Data

Dataset terdiri dari 50 putusan pengadilan narkotika.

Setiap anggota bertanggung jawab terhadap proses ekstraksi data sesuai pembagian kelompok. Data yang telah diekstraksi dicatat dalam `data/putusan-50.csv`, sedangkan sumber setiap atribut dicatat dalam `docs/data-provenance.csv`.

Informasi provenance meliputi:
- Case ID
- Nama atribut
- Nilai atribut
- File sumber
- Halaman sumber
- Extractor
- Reviewer
- Status verifikasi

Identitas terdakwa disamarkan menggunakan kode anonim.

## 5. Kontribusi Pengujian

Pengujian dilakukan menggunakan JUnit 5 dan pengujian manual melalui aplikasi.

Pengujian mencakup:
- Pengujian jumlah data putusan.
- Pengujian pencarian data.
- Pengujian tambah dan hapus data.
- Pengujian filter dan filter gabungan.
- Pengujian agregasi dan pengurutan.
- Pengujian struktur data.
- Pengujian impor data tidak valid.
- Pengujian ekspor dan riwayat operasi.

Bukti pengujian disimpan dalam folder `docs/demo/` dan `docs/trace/`.

Setiap anggota bertanggung jawab atas kontribusi yang dikerjakan masing-masing. Proses pengembangan dilakukan melalui GitHub Issues, branch, commit, Pull Request, dan code review.
